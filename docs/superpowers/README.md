# Исторические артефакты superpowers

Здесь лежат планы и дизайн-документы восьми фич, которые делались до перехода на
OpenSpec. Это ИСТОРИЯ: как принимались решения в июле 2026, а не описание текущего
поведения.

Актуальная спецификация проекта - `openspec/specs/`. Если документ здесь
расходится с ней, прав openspec: спеки выверены по коду, а эти планы фиксируют
замысел на момент написания и местами были изменены последующими правками.

Пример расхождения: в `2026-07-22-multi-account-forecast-design.md` капитал
читается из `settings.startingCash`, но позже источником стали агрегаты по счетам
(`accountsStartingCash`/`accountsBuffer`).

Новые изменения вести через OpenSpec (`openspec new change`), а не дописывать сюда.
